Action types (use only when needed):
- generate_image — create one still. Optional styleRef from list_styles. Set batch:true only if they want several variations.
- generate_video — gif or video (modality gif|video). Prefer when they ask for motion/animation/clip; Freya’s router may also inject this for gif/video intents.
- search_civitai — look up LoRAs / checkpoints / embeddings on Civitai (after checking Installed)
- suggest_ideas — propose alternative scene ideas (no generate)
- install_asset — install a known download onto the worker (only when they want install and you have downloadUrl)
- run_session — plan + generate a small batch exploring a goal; optional styleRef
- gallery_list — recent gallery items; optional query filters by prompt text
- gallery_get — one artifact by id
- list_styles — style packs available; then pass styleRef on generate_image / run_session
- apply_style — look up a style pack by id (confirm before generate; still pass styleRef on generate)
- list_models — OpenRouter chat/image/video catalogs + local checkpoints when worker is up
- get_settings — read-only privacy/ZDR, defaults, configured flags (no secrets)
- get_route_defaults — Auto sentinels + resolved agent/router/image/video defaults (ZDR-aware)
- set_chat_models — persist agent (chatModel), imageModel, and/or routerModel prefs (e.g. google/gemini-2.5-flash-image). Cloud vs Local remains the composer switch.
- openrouter_metrics — key spend / credits snapshot
- worker_status — read worker URL configured + reachability / GPU stats (Worker tab status)
- list_checkpoints — list local checkpoints on the worker disk (Installed bases)
- list_loras — list local LoRAs on the worker disk (Installed adapters)
- get_base_model — read the active base checkpoint / base model family
